# List my projects

As a member, I want to see my projects page by page, so that I can find the one I want.

## Acceptance criteria

- A member sees only their own projects.
- The list comes in pages. The request says the page and the page size.
- The response says the total count.
- Deleted projects do not show.

## Questions

- Which order by default: newest first?
- What is the largest page size allowed?
