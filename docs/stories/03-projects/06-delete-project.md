# Delete my project

As a member, I want to delete a project I no longer need, so that it stops showing in my lists.

## Acceptance criteria

- A member deletes their own project.
- A deleted project no longer shows anywhere, and neither do its tasks.
- The project stays in the database, marked as deleted.
- Another member's project cannot be deleted.

## Questions

- Can a member restore a deleted project? The brief does not say.
- What happens to the project's work sessions, attachments, favorites and comments?
