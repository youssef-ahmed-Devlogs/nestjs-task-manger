# Cancel a session

As a member, I want to cancel a planned session, so that its time is free again.

## Acceptance criteria

- A member cancels their own session.
- A cancelled session frees its time: a new session can take it.
- A cancelled session cannot be changed.

## Questions

- Can a past session be cancelled? The brief says a past session cannot be changed, and does not say whether cancelling is a change.
