# Edit a task

As a member, I want to change my task, its status included, so that it shows where my work is.

## Acceptance criteria

- A member changes any field of their own task, the status included.
- The category and the tags must be ones an admin created.
- Another member's task, or a deleted one, cannot be changed.
- Each invalid field gets its own validation error.

## Questions

- Can a task move to another of my projects?
