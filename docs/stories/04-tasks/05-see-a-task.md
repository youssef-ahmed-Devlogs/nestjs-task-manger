# See a task

As a member, I want to see one of my tasks, so that I can check all its details.

## Acceptance criteria

- A member sees one of their own tasks, with every field, and its category and tags by name.
- A deleted task gets a 404.
- Another member's task gets the same answer as for another member's project ([See a project](../03-projects/04-see-a-project.md)).
