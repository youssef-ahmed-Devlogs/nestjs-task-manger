# Delete a task

As a member, I want to delete a task I no longer need, so that it stops showing in my lists.

## Acceptance criteria

- A member deletes their own task.
- A deleted task no longer shows anywhere, and is not counted in the project stats.
- The task stays in the database, marked as deleted.
- Another member's task cannot be deleted.

## Questions

- Can a member restore a deleted task?
- What happens to the task's work sessions, attachments, favorites and comments?
