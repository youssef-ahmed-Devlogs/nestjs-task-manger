# List the tasks of a project

As a member, I want to see the tasks of one of my projects page by page, so that I can see what is in it.

## Acceptance criteria

- A member sees the tasks of one of their own projects, page by page, with the total count.
- Deleted tasks do not show.

## Questions

- Is there also one list of all my tasks, across my projects? The brief says "lists of tasks" without saying where.
- Which order by default: due date first?
