# Upload files to a task

As a member, I want to upload files to one of my tasks, such as images and PDFs, so that what I need for the task is in one place.

## Acceptance criteria

- A member uploads one or more files to their own task.
- Only allowed types are accepted, such as images and PDFs. The type is checked from the file's content, not only from its name or from the type the client sends.
- A file larger than the size limit is refused.
- A task never holds more files than the count limit.
- Files are kept in the file storage, not in the database.
- **(proposed)** Each file is stored under a name the system makes, not the name the client sent. Source: [File Upload Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/File_Upload_Cheat_Sheet.html), "Change the filename to something generated by the application".
