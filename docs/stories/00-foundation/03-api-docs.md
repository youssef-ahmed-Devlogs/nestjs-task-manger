# Interactive API docs

As a developer of a client app, I want interactive docs for the API, so that I can see and try every endpoint.

## Acceptance criteria

- The docs list every endpoint, with its input and every response it can give, errors included.
- I can try any endpoint from the docs.
- The docs show which endpoints need a token, and let me add one to try them.
