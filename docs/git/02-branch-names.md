# Branch names

```
<type>/<story-number>-<story-name>
```

- `type`: `feat` for a story, `fix` for a bug, `chore` for work that is not a story.
- `story-number`: the folder number, then the file number. `02-01` is `stories/02-admin-lists/01-manage-categories.md`.
- `story-name`: the file name, without its number and `.md`.
- Lowercase letters, digits and hyphens only.

```
feat/02-01-manage-categories
fix/02-01-duplicate-category-name
chore/update-nestjs
```

Source: [Conventional Branch](https://conventionalbranch.org/)
